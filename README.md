# Invitación para Jhetsyn 🌸

Invitación interactiva y personal para el concierto de **Antología** el **17 de octubre**.

## Cómo usarlo

1. Sube esta carpeta a un repositorio de GitHub.
2. Activa **GitHub Pages** (Settings → Pages → Deploy from main branch).
3. (Opcional) Sube tu archivo de audio en piano como `audio.mp3` en la misma carpeta.
4. Comparte el enlace con Jhetsyn.

## Personalizar el audio

- **Opción 1 (recomendada)**: Graba o exporta tu versión en piano como `audio.mp3` y colócalo junto al `index.html`.
- **Opción 2**: Abre `index.html`, busca el comentario de YouTube y descomenta el `<iframe>` poniendo el ID del video de Antología que quieras.

## Colores y estilo

- Fondo negro
- Acentos en fucsia
- Flores como elemento principal
- Efecto de camino (barra de progreso + botones "No" que se escapan)
